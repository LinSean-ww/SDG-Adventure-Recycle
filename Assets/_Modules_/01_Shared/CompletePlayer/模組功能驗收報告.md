# CompletePlayer v1.1 模組功能驗收報告

## 功能與責任

共用核心包含角色移動、視角、趴下與探頭、互動、暫停／操作設定、任務清單、按鍵自訂和 PlayerPrefs 儲存。Tab 與五格快捷欄由 PlayerInputService 提供可重新綁定的事件。Demo 場景另有 CompletePlayerDemoInventory，顯示背包測試面板和五格選取狀態；該測試元件不在 CompletePlayer Prefab 中，不會強制加入其他關卡。正式物品資料、撿取、裝備和背包系統仍由關卡自行實作。

## 驗證與限制

- 使用 Unity 2023.1.22f1，原專案和獨立匯入專案均執行 Complete Player Validate；檢查涵蓋核心元件、Prefab／Demo 的 Missing Script 和序列化 Missing Reference、Input Actions、UI 字型及 OFL 授權，並檢查沒有 Level03 資產依賴。
- v1.1 在獨立專案執行 Play Mode 元件與模擬輸入測試：第三人稱 Renderer、相機圖層及跟隨、背包開關、Esc、五格選取、改綁、設定 UI 和既有設定回歸。實際畫面、實體滑鼠與鍵盤手感仍需人工驗收；自動化通過不等於畫面已通過人工驗收。
- 需要 Input System 1.7.0、Unity UI 1.0.0 和 Both 輸入模式。PlayerPrefs 設定依目標專案保存。第三人稱工人會以軀幹與頭部表現探頭，鏡頭不隨之偏移。
- 中文 UI 字型附 SIL OFL 授權與公告。角色 fk.fbx 複製自原有素材，其作者與再散布授權未見專案文件，對團隊外散布前須向素材提供者確認。

## v1.2 工人外觀與姿勢

共用工人外觀與未持武器姿勢取自 C_Main 工人的建立參數與公式；使用共用 Rust／Steel 貼圖，不依賴 C3 控制器、武器或關卡。原專案 Play Mode 自動對照工人階層、尺寸、材質和站立／蹲下／趴下、走跑及離地條件下姿勢，並驗證第一／第三人稱 Renderer 狀態；Demo 輸入與設定回歸也執行。以上為程式層級驗證，不代表實際畫面、腳底貼地或持武器姿勢已通過人工驗收。正式武器系統未包含。使用者將自行在既有 TEST 專案匯入並人工驗收。

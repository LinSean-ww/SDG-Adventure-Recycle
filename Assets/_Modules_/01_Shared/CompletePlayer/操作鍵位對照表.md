# 操作鍵位對照表

| 功能 | 預設 |
|---|---|
| 前進／後退／左移／右移 | W／S／A／D |
| 視角 | 滑鼠 |
| 跳躍 | Space |
| 奔跑／蹲下／趴下 | 左 Shift／左 Ctrl／Z |
| 左／右探頭 | Q／E |
| 互動 | F |
| 背包輸入 | Tab |
| 快捷欄 1～5 輸入 | 1／2／3／4／5 |
| 任務清單／暫停 | P／Esc |
| 裝填／丟棄輸入 | R／G |

按 Esc > 操作設定，可逐項改綁；五個快捷格可各自設定。設定會檢查衝突、存入 PlayerPrefs，並可恢復預設；滑鼠靈敏度、跑步與蹲下模式也可設定。R 裝填與 G 丟棄均為可改綁的共用輸入；實際彈藥管理和物品掉落須由關卡整合。舊有儲存鍵位若與 G 衝突，系統會為丟棄選取其他未使用鍵位，請在設定中確認。核心模組的背包和快捷欄提供輸入事件；Demo 顯示測試背包與五格選取 UI。各關卡仍需自行實作正式介面與物品功能。第三人稱工人會以軀幹與頭部表現探頭，鏡頭不隨之偏移。
